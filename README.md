# Atelier Norr

A premium React template for architecture, interior design, and creative studios. Built with Vite, React, Tailwind CSS, and Framer Motion.

## Features

- **Modern Architecture Studio Aesthetic**: Clean typography, bold imagery, and sophisticated color palettes.
- **Smooth Animations**: Page transitions, scroll reveals, and elegant micro-interactions using Framer Motion.
- **Responsive Layout**: Designed to look stunning on all devices, from mobile to desktop.
- **Built for Speed**: Vite provides blazing fast HMR and optimized production builds.
- **Easy Customization**: Built entirely with Tailwind CSS, making global style changes effortless.

## Development

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Start Development Server**
   ```bash
   npm run dev
   ```
   Or use the included startup scripts:
   - Windows: Double click `start.bat`
   - PowerShell: Run `.\start-server.ps1`

3. **Build for Production**
   ```bash
   npm run build
   ```
